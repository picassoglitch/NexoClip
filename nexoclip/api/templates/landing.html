What makes it different

Voice-marker triggers

Streamers say clipea esto (clip the next 30s) or clipeaste eso (clip the previous 60s) as natural verbal bookmarks. Custom phrases configurable per brand kit.

Per-speaker brand kits

Speaker diarization (pyannote-audio) routes each clip in a multi-streamer VOD to the right host's colors, fonts, social handles, and captions. Speaker identities persist across VODs via embedding match.

AI captions + logos

Anthropic Claude generates persona-flavored captions, viral hooks, and SVG brand logos. Cost-tracked per call; structured output validated against Pydantic schemas.

Local GPU transcription

faster-whisper runs on your own GPU. No cloud upload of stream audio required — your VODs never leave your machine for transcription.

Auto-publish with undo

Per-kit opt-in. Clips queue with a scheduled-for timestamp; the operator can cancel from the inbox before the worker fires. Review-first stays the default.

MCP-ready for agents

Drive NexoClip from Claude Code, Cursor, or any MCP client. The MCP surface mirrors the REST API — list streams, kick off pipelines, fetch clips conversationally.

The loop

Designed to be the one thing a streamer touches each morning:

  1. 1 · ingest Upload VOD or watch a Drive folder

    Drag-drop on the dashboard, or connect Google Drive once and drop your OBS recordings there.

  2. 2 · diarize + transcribe Speakers labeled, words timestamped

    pyannote-audio assigns SPEAKER_00..N and faster-whisper produces a word-level transcript on your GPU.

  3. 3 · detect Voice markers + chat heat + visual signals

    Forward and retroactive trigger phrases, plus audio peaks and scene cuts, become candidate timestamps.

  4. 4 · cut + brand Vertical clips with the right brand kit

    ffmpeg cuts each window, smart-crops to 9:16 around the active face, and burns in the per-speaker handle.

  5. 5 · variants Captions + hooks per platform

    Claude writes persona-flavored captions and hashtags for TikTok, Shorts, Reels in your target languages.

  6. 6 · publish or review Inbox with one-click cut + undo

    Clips land grouped by VOD and speaker. Auto-publish kits queue with an undo window — manual review otherwise.

Frequently asked

Who is NexoClip for?
Streamers who finish a stream and want clips ready by morning, multi-host stream collectives that need per-streamer branding within one VOD, and agents / MCP clients that want to drive a clipping pipeline programmatically.
Do I need a GPU?
A consumer GPU (RTX 4060+ recommended) handles Whisper + pyannote comfortably for ~4hr VODs. CPU-only mode works for short clips (set NEXOCLIP_WHISPER_DEVICE=cpu) but is much slower.
Which LLM does NexoClip use?
Anthropic Claude exclusively. The router supports adding more providers later without code changes, but the live surface is Claude-only — the structured-output reliability is essential for the variant generator and viral-moment selector.
How do I integrate NexoClip into an agent workflow?
Run nexoclip mcp serve --token <api-token> to expose the MCP server over stdio. Claude Code, Cursor, and other MCP clients will see tools for listing streams, kicking off pipelines, fetching clips, and managing brand kits. The same tenant token gates the JSON REST API at /streams, /clips, etc.
What about retention and data privacy?
Per-tenant retention windows (default 30 days for VODs, 90 for clips, 365 for transcripts) — all configurable. Daily sweeper hard-deletes past-cutoff artifacts. No soft-delete bin. Audio + video stay on your machine for transcription; only the LLM caption-generation step calls out to Anthropic.
Is there an API I can call directly?
Yes. OpenAPI spec + interactive Swagger UI. Issue a token via nexoclip tokens issue --tenant <id> --scope full and pass it as Authorization: Bearer <token>.
